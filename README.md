# InsightFlow AI

InsightFlow AI is an AI-powered platform that converts audio and video content into clear, meaningful insights.

## Top Features

- Upload audio and video files
- Convert speech into text using OpenAI Whisper
- Generate AI-powered summaries
- Extract important key points
- Create structured Markdown insights
- View and edit generated content
- Save insights for future reference
- Secure user authentication
- Responsive and user-friendly interface

## How It Works

1. Sign in securely.
2. Upload an audio or video file.
3. The file is transcribed automatically.
4. AI analyzes the transcript.
5. A summary and key points are generated.
6. Review, edit, and save your insight.
